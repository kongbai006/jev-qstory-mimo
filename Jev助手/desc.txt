Jev 助手（Mimo 版）v1.7 正式版 — QStory 可加载插件

功能：读取消息 → **秒弹「快速意图 + 危险等级 + 情绪百分比」**（本地毫秒级）→ 可选调用大模型 → 更新成完整候选 → 点「发送」才发出。从不自动发送。

使用方法：
1. 把 Jev助手/ 目录放进 QStory 的脚本/插件目录（和你导入这两个参考插件的方式一样），重启 QQ；
2. 打开 QQ → 任意聊天窗口 → QStory 悬浮窗菜单 → **「Jev 设置」**，一个弹窗搞定全部：
   - **顶部：第二轮大模型总开关**（开关打开 = 调 API 出 3 条候选；关闭 = 只秒弹本地判断，不消耗 token）
   - **中间：API 与模型**——API 地址 / API 密钥 / 模型 / 最近消息条数 / 默认关系描述 / 群聊触发，全部手机上直接填
   - **底部：「测试API」「保存」** 两个按钮
3. 点「测试API」一键验证当前密钥/地址/模型是否可用（显示耗时和模型返回）；
4. 点「保存」立即生效；
5. 「本会话关系设置」：每个聊天对象单独填关系（如"对方是我的暧昧对象"），互不影响；
6. 私聊默认自动分析；群聊默认需 @ 机器人。

诊断排障：
- 悬浮窗菜单「Jev 诊断」直接看运行日志；也写在插件目录 jev_diag.log；
- 「测试API」失败 → 按弹窗提示检查 API 地址/密钥/网络；
- 没有弹窗 → 检查「开启本会话分析」是否开、群聊是否 @ 了机器人。

说明：密钥只存在你的插件目录 config.json 里，不会写进聊天记录。
