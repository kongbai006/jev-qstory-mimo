# Jev 助手 · QStory 版

基于 **QStory 插件框架** 的聊天辅助工具。对方私聊发消息后，**本地毫秒级**弹出「意图 + 危险等级 + 情绪百分比」；可选调用小米 MiMo 大模型生成 3 条候选回复，**手动确认才发送，绝不自动发消息**。

> 本仓库是 **QStory（Java 插件）版本**，需要 QStory 环境加载。
> Nuke 版本（JS 脚本）请见另一个仓库：`kongbai006/jev-nuke-mimo`。

## 功能

- 收到私聊文本 → 立刻弹窗显示：意图 / 危险等级(1-9) / 情绪（开心·难过·生气 百分比）；
- 结合最近若干条消息做本地关键词判断，不联网也能秒出结果；
- 可选开启第二轮：调用 MiMo 返回 3 条候选回复，逐条问你「发送？」，确定才发；
- 群聊默认需要 @ 触发，也可在设置里改成只处理私聊。

## 环境要求

- 已安装 **QStory**（支持加载 `.jar` / 脚本插件的 QQ 框架）；
- 需要 MiMo 大模型 API 密钥（`sk-` 开头）；只用本地判断则不需要联网。

## 安装

1. 下载本仓库 Release 里的 `jev-qstory-plugin-mimo.zip`；
2. 解压，把里面的 `Jev助手/` 文件夹放进 QStory 的插件目录；
3. 重启 QQ / 重载 QStory；
4. 打开任意聊天 → QStory 悬浮窗菜单 → **「Jev 设置」**；
5. 在弹窗里填写：
   - 第二轮大模型总开关（开 = 调 API 出候选，关 = 只本地判断、不耗 token）；
   - API 地址（默认 `https://api.xiaomimimo.com/v1`）；
   - API 密钥（`sk-` 开头）；
   - 模型（默认 `mimo-v2.6-flash`）；
   - 最近消息条数、关系描述等；
6. 点「测试 API」验证连通，再点「保存」。

## 可修改选项

| 选项 | 位置 | 说明 |
| --- | --- | --- |
| API 密钥 | 设置弹窗 / `Jev助手/config.json` | `sk-` 开头，默认占位符 |
| API 地址 | 设置弹窗 / `config.json` | 默认 `https://api.xiaomimimo.com/v1` |
| 模型 | 设置弹窗 / `config.json` | 默认 `mimo-v2.6-flash` |
| 最近消息条数 | 设置弹窗 / `contextRounds` | 发给 AI 的上下文条数 |
| 关系描述 | 设置弹窗 / `relationship` | 如「对方是我暧昧对象」 |
| 群聊触发 | 设置弹窗 / `groupTrigger` | `at` = 群里 @ 才触发 |
| 总开关 | 设置弹窗顶部 | 关闭后不调用 AI |

密钥只存在你本地插件目录的 `config.json` 里，不会上传。

## 说明

- 情绪只分 **开心 / 难过 / 生气** 三类；
- 判断结果仅供娱乐参考；
- 本工具不绕过任何平台安全机制。
