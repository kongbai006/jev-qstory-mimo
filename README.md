# Jev 聊天助手 · QStory 版

适配 **QStory** 框架的 Java 插件。对方私聊发消息后，本地立刻判断意图 / 危险等级 / 情绪；可选接入**任意 OpenAI 兼容大模型**（小米 MiMo、DeepSeek、通义、智谱、OpenAI 等）给出建议和 3 条候选回复，候选自动复制到剪贴板，**手动粘贴发送，绝不自动发消息**。

> 同系列：
> - WA (WAuxiliary) 版：`kongbai006/jev-wa-mimo`
> - WeKit 版：`kongbai006/jev-wekit-mimo`
> - Nuke 版：`kongbai006/jev-nuke-mimo`

## 安装

把 `Jev助手/` 整个文件夹拷到 QStory 的插件目录下，重启 QStory / 微信后启用。

## 配置

在聊天框输入 `/jev` 打开配置：API 地址、密钥、模型、关系描述、上下文轮数等。默认接入小米 MiMo，可改成任意 OpenAI 兼容端点。

## 解压目录说明（重要）

**不要**把 zip 里的文件直接散着解压到模块的插件根目录。模块是按「一个子文件夹 = 一个插件」来识别的：

```
<插件根目录>/
├── Jev助手/              ← 这个文件夹叫什么，插件列表里就显示什么名字
│   ├── info.prop
│   ├── main.java
│   ├── config.json
│   └── ...
├── 另一个插件/
│   └── ...
└── ...
```

- 文件夹名就是插件在列表里的显示名；
- 直接把 `main.java`、`info.prop` 散在插件根目录下是识别不出来的。

## 行为说明

- 只分析单人私聊，群聊忽略；
- 情绪分 开心 / 难过 / 生气，无匹配显示「平静」；
- 候选回复**不会自动发**，自动复制到系统剪贴板，微信输入框长按粘贴后挑一条发；
- 判断结果仅供娱乐参考。
