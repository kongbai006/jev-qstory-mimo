# Jev 助手（MiMo 版）

基于 [QStory](https://github.com/) 脚本引擎的 QQ 聊天辅助插件。对方一发消息，本地秒判意图/情绪/危险等级，可选调用小米 MiMo 大模型生成 3 条候选回复供你参考。**从不自动发送任何消息**。

> 本项目仅供学习交流与娱乐，判断结果仅供参考。

## 功能

- **秒级读懂对方**：对方发消息瞬间，本地给出「对方意图」「危险等级(1-9)」「情绪百分比(开心/难过/生气)」，不依赖网络；
- **AI 拟回复**：可选调用大模型，生成 3 条风格不同的候选回复（稳妥/走心/幽默），附建议动作；
- **绝不自动发送**：所有回复需手动点「发送」才发出；
- **按人分别设置**：每个聊天对象可单独填写关系描述，AI 判断更贴合你们的语境；
- **总开关**：第二轮 AI 回复可一键关闭，关闭后只显示本地秒判，不消耗 token；
- **纯手机端配置**：API 地址/密钥/模型/上下文条数全部在弹窗内填写，一键测试连通性。

## 安装

1. 把 `Jev助手/` 整个目录放进 QStory 的插件目录，重启 QQ；
2. 任意聊天窗口打开 QStory 悬浮窗 →「Jev 设置」→ 填入你的 MiMo API 密钥 → 点「测试API」确认连通 →「保存」；
3. 对方发消息即自动弹出分析。

## 配置

| 项 | 默认 | 说明 |
|---|---|---|
| baseUrl | https://api.xiaomimimo.com/v1 | MiMo API 地址 |
| apiKey | 空 | 你的密钥，sk- 开头，在 MiMo 控制台获取 |
| model | mimo-v2.6-flash | 模型名 |
| contextRounds | 8 | 发给 AI 的历史消息条数（2~30） |
| groupTrigger | at | at=被@才分析 / all=群里每条都分析 |

> 关系描述建议通过悬浮窗「本会话关系设置」按聊天对象单独填写，无需手改文件。
